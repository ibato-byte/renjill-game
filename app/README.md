# レンとジルのチモシーダッシュ（アプリ版）

このフォルダをそのままWebに置くと、スマホの「ホーム画面に追加」でアプリとして使えます。
アイコンから全画面で起動し、一度開けば電波がなくても遊べます。

## 1. 公開する（無料・5分）

いちばん簡単なのは **Netlify Drop** です。

1. https://app.netlify.com/drop を開く（無料アカウントを作るとURLがずっと残ります）
2. この `app` フォルダごと、画面にドラッグ＆ドロップ
3. 表示されたURL（例: `https://xxxx.netlify.app`）がアプリの住所です
4. 好きな名前にしたいときは「Site configuration → Change site name」

ほかに GitHub Pages、Cloudflare Pages、Firebase Hosting でも同じように置けます（どれも無料枠あり）。
※ `https://` のURLで公開してください（ホーム画面アプリとオフライン動作に必要です）。

## 2. スマホに入れる

- **iPhone（Safari）**：URLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：URLを開く → 右上のメニュー → 「アプリをインストール」（または「ホーム画面に追加」）

## 3. ランキングを動かす（任意・無料）

何もしなくてもゲームはすべて遊べます（ランキングだけ「準備中」と表示されます）。
みんなのランキングを使うときは、Googleの **Firebase**（無料プランで十分です）を設定します。

1. https://console.firebase.google.com を開き「プロジェクトを追加」（名前は自由、Googleアナリティクスはオフで可）
2. 左メニュー「構築 → Authentication」→「始める」→「ログイン方法」で **匿名** を有効にする
3. 左メニュー「構築 → Firestore Database」→「データベースを作成」
   - ロケーション：`asia-northeast1（東京）`
   - 「本番環境モード」で作成
4. Firestore の「ルール」タブを開き、このフォルダの `firestore.rules` の中身をまるごと貼り付けて「公開」
5. プロジェクトの設定（歯車）→「マイアプリ」→ ウェブ（`</>`）を追加 → 表示される設定から
   `apiKey` と `projectId` を、このフォルダの `config.js` に貼り付ける

   ```js
   window.HAYDASH_CONFIG = {
     firebase: { apiKey: 'AIza....', projectId: 'your-project-id' },
     url: 'https://xxxx.netlify.app/'
   };
   ```
6. `config.js` を保存して、もう一度 Netlify Drop にフォルダをドロップ（上書き公開）

これで、遊んだ人の記録が自動で月間ランキングに載ります（名前を決めていない人は「うさぎ#番号」）。

### 安全のためのおすすめ設定
- Google Cloud コンソール →「APIとサービス → 認証情報」で、この `apiKey` に
  「ウェブサイトの制限」として公開したURL（例 `https://xxxx.netlify.app/*`）を設定すると、ほかのサイトから使われません。
- `apiKey` はWebアプリでは公開される前提の値です。書き込みは `firestore.rules` で「自分の記録だけ・常識的な値だけ」に制限しています。

## 4. 更新するとき
ゲームを更新したら、新しい `app` フォルダを同じ場所にドロップするだけです。
次にアプリを開いたとき、自動で新しい版に入れ替わります（`config.js` は上書きしないよう、設定済みのものを残してください）。

## データの引き継ぎ（機種変更・将来のiOS/Androidアプリ）
- ゲームの「⚙ 設定 → データ引き継ぎ」で **引き継ぎコード** を作れます。新しい端末の同じ画面に貼り付けると、記録・チモシー・購買部の品・キャリア・ランキングの名前がそのまま移ります（写真アルバムは除く）。
- 記録には端末ごとに変わらない **プレイヤーID（pid）** が入っています。将来ストア向けアプリを作るときも、同じゲームのコードを使えばこのコードをそのまま読み込めるので、アカウントを引き継げます。
- ランキング（Firebase）を使っている場合は、ランキングのアカウントも一緒に移ります。

## アプリ版での違い
- ジルのチャット：AIの会話は claude.ai 版だけの機能のため、アプリ版ではよくある質問に答える簡易版になります。
- シェア：X・LINE・Facebook・Instagram・リンクのコピーは、アプリ版のURLで動きます。

## フォルダの中身
| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体 |
| `config.js` | ランキング（Firebase）の設定と、公開URL |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | オフラインで遊べるようにする仕組み |
| `./` | ホーム画面のアイコン |
| `firestore.rules` | ランキングの書き込みルール（Firebaseに貼り付ける） |
