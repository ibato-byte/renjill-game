# 2026-11-19 ホーム画面（メニュー画面）の一新とブラッシュアップ

## オーナーの依頼
- 「メニュー画面を一新して、もっと高品質なデザインに。ゆるキャラのゲームのホーム画面を参考に、web とスマホの両方。ほかのゲームの良い所も取り入れてよい」
- 「一新できたら、そこから 100 以上のブラッシュアップを様々な角度で。最高のクオリティに。AI 独特の文字が強い感じは避けて」

## 取り入れた考え方（絵・キャラクターはまねしない）
- 部屋と 3 人が主役。ベージュの大きな札をやめ、景色をそのまま見せる。
- 上に細い状態の帯（ベスト・チモシー・音・設定、昇進）。
- 文字のボタン → 絵のついた丸いボタン（左右の列）。
- 「今日の目標」は 3 人の上のふきだし。
- 下の台は、キャラクターえらび（丸い顔）とスタート（金色）だけ。
- ボタンの種類・id・動きは前と同じ。新しい遊び方は足さない。

## 作り方
- 見た目の元：tools/home/home.css。絵のボタン（SVG）は tools/home/gen.py が作り、src/head.html の `HOME-V2 START〜END` の間に入れる。
- 直す時：home.css を直す → `python3 tools/home/gen.py` → `python3 build.py`。
- src/body.html：#sTitle に class="home"。src/7_ui.js：音のボタンのしるし（off）、お知らせの帯の場所（toastPlace）。

- スマホ（たて・横）、PC、英語のせまい画面の 4 つの形。
