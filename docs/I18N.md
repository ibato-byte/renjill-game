# 多言語（日本語・English・繁體中文・한국어）

公式サイト（renjill.coana.co.jp）と同じ4言語。タイトル画面の🌐ボタンで 日本語 → English → 繁體中文 → 한국어 と切り替わる（初めての人は端末の言語で始まる。`?lang=zh` などでも開ける）。

## しくみ
- 日本語と英語は今までどおりソースの中（`['日本語', 'English']`・`{ ja, en }`・`tr('日本語', 'English')`）。
- 中国語（台湾の繁体字）と韓国語は **i18n.json**（リポジトリの一番上）。日本語の文がそのまま鍵：`{ "日本語の文": { "zh": "…", "ko": "…" } }`。
- build.py が i18n.json から src/0_i18n.js を作る（手で直さない）。訳がない文は英語で出る。
- 文を足すときは日本語・英語に加えて i18n.json に zh・ko を足す。{0} などの差し込みと改行の数をそろえる。
- 確かめる：`node qa/i18n_audit.js`（全画面と走っている間をまわり、訳のない文・カナの残りを数える。0 で合格）。

## 訳のきまり
- 名前：レン=Ren、ジル=Jill、ポム=Pom（公式サイトと同じ。中国語は漢字の横に半角スペース）。チモシー=牧草/건초。タイトル=Ren & Jill：Hay Dash / Ren & Jill: Hay Dash。もぐもぐフィーバー=嚼嚼狂熱/냠냠 피버。購買部=福利社/매점。伝説のうさぎ=傳說之兔/전설의 토끼。
- 地名はその言語のふつうの書き方（渋谷=澀谷/시부야）。建物は説明だけ（実在の名前・ブランド名は出さない）。
- 「AI」「Claude」は画面に出さない。町の看板（カフェ・うどん など）は東京の景色なので日本語のまま。
