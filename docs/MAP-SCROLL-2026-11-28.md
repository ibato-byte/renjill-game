# 画面が途中から開くバグと、スタンプ帳の大きな地図（2026-11-28）

## オーナーの声
- 「ミッションのボタンをスクロールして、その後スタンプ帳などを開くと、ページが上部の一番最初から表示されず、途中から表示されてしまうバグがある。他でもこれが発生していないか確かめた上、改善して」
- 「スタンプ帳の地図はまだ小さくて非常に見づらいので改善して」

## 1. 画面が途中から開くバグ（しるし [スクロール]）
- わけ：ホームから開く 10 の画面（ミッション・スタンプ帳・えさ図鑑・購買部・あそびかた・ランキング・きろく・練習・設定・言葉）は、どれも同じ「中身の箱」（#pBody）を使っている。箱は前の画面のスクロールの位置を覚えていて、開く時に 0 にもどしていたが、**画面をかくしている間に 0 にしていた**ので効かなかった（見えない箱にはスクロールの位置が入らない）。
- 調べた所：ミッション → スタンプ帳は 1,532px、スタンプ帳 → えさ図鑑・えさ図鑑 → 購買部は 144px、購買部 → あそびかたは 1,052px、設定 → ミッションは 1,297px の所から開いていた。同じ画面を開き直しても途中から。パソコンでも同じ。
- 直し：画面を出した**直後**（見えるようになってから）に一番上にもどす。画面を出す決まりの所（show）でまとめてやるので、結果画面なども同じ（前の回にスクロールした位置が残らない）。会話の箱（ユズに聞く）は、新しい言葉が下にあるので、そのまま。
- 画面の中の並べかえ（スタンプ帳の「よく行く順」など）は、今まで通り見ていた所のまま（上へ飛ばない）。
- 試験：qa/panelscroll.js（9 つの画面を順に、下までスクロール → 閉じる → 次を開く が 0 から／閉じずに切りかえ／同じ画面の開き直し／並べかえでは位置を保つ／結果画面）。直す前のもので 12 か所落ちることを確かめてから直した。

## 2. スタンプ帳の地図（しるし [地図 M番号]）
| 番号 | 中身 |
|---|---|
| M1 | 地図の絵を作る所を分けて、「大きく見る」画面でも同じ地図を使う |
| M2 | 小さな地図の印をひと回り大きく（行った所 3.8 → 4.6・まだの所 2.2 → 2.8） |
| M3 | 印を押せる広さ 7 → 8.5 |
| M4 | えらんだ名所のふき出しも、大きく見る画面では画面の上で同じ大きさ |
| M5・M24 | 「東京ぜんぶ」「都心」のとなりに、金色の「大きく」ボタン |
| M6 | 「大きく」か、地図そのもの（印でない所）を押すと、画面いっぱいの地図が開く |
| M7 | 2 本の指でつまんで拡大・縮小、1 本の指で動かす（パソコンはホイールと、つかんで動かす） |
| M8 | 2 回つづけて押すと、その場所を 2 倍に |
| M9 | ＋・−・全体のボタン（指 1 本でも使える） |
| M10 | 拡大しても、名所の印・駅や川の名前は画面の上で同じ大きさ（拡大すると、重なっていた印が分かれて見える） |
| M11 | 開いた時は画面の高さいっぱいに広げ、えらんでいる名所（なければ都心）をまん中に |
| M12 | 名所の印を押すと、名前とスタンプの絵のふき出し（後ろのスタンプ帳にも同じ所がえらばれる） |
| M13 | 地図が画面の外へ行きすぎないように止める |
| M14 | ✕・Esc で大きな地図だけを閉じる（スタンプ帳は開いたまま） |
| M15 | 動きを減らす設定では、ズームの動きもすぐに |
| M16 | 開いた時だけ、指の使い方の小さな札（2.5 秒・さわると消える） |
| M17 | 閉じたら、キーボードの選択を「大きく」のボタンにもどす |
| M18 | 画面を回した時も、見ていた所を保つ |
| M21 | 小さな地図の字：駅の名前 7.5 → 9.5・川や湾の名前 8 → 9.5 など |
| M22 | スマホでは、小さな地図を札の左右いっぱいに |
| M23 | 地図の上では、指のマークが「虫めがね」 |
| M25 | 大きく見る画面で拡大した時は、行った名所の名前を印のとなりに（駅の名前や、ほかの名前と重なる所は出さない） |
| M26 | 押した所にいちばん近い名所をえらぶ（並んでいる所で、上に重なった別の印がえらばれていた） |
| M27 | スタンプ帳の小さな地図も、押した所にいちばん近い印をえらぶ（14 ドット以内） |

- 試験：qa/mapbig.js（スマホ 390・320、パソコン 1280、日本語・英語）。画面いっぱい・駅の名前 12px 以上（開いた時は 17px）・＋で拡大しても印の大きさが同じ（10px → 10px）・2 本の指で広げると拡大・1 本の指で動く・印を押すとえらばれて後ろのスタンプ帳にも出る・Esc と ✕ で閉じる・スタンプ帳を閉じると大きな地図も消える。
- 文字：「大きく」「拡大」「縮小」「全体」「東京スタンプラリーの地図」「2本の指で拡大・1本の指で動かす」などを i18n.json（中国語・韓国語）に足した。
