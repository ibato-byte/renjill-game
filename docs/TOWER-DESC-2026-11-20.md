# 2026-11-20 電波塔：降りる時のぐるっと・着地の道・塔の向きの矛盾・登る時のチカチカ（50 以上の改善・確認・仕上げ）

## オーナーの言葉
- 「東京タワーやスカイツリーから降りるときに、これまでは景色をぐるっと見てから降りるようになってたのに、真下にまっすぐおりるようになってしまったので、前の方がよかったです」
- 「降りるときの道路がやすっぽくなってるのと、道路がぐるっと景色をするのに合わせて動いてしまっておかしくならないように」
- 「東京タワーが正面に見えていたのに、右に曲がったらまた見えるような矛盾もありました」
- 「まだ全体的にチカチカ障害物がすることがあり、特にタワーを登るときに多いです」

## 原因
- 降りる時：11-20 の第 1 回（D1）で「道が動いて見える」をなおすため、1 回転をやめて左右に ±20 度だけ見るようにしていた。
- 塔の向き：コースの曲がる向き（右・左）が毎回その時しだいなのに、場所ごとの「向き（face）」は決まった数だった。右に曲がっても左に曲がっても、塔や山は同じ方角に描かれ、正面に見えていた塔が、曲がったあともまた正面に出ることがあった。
- 登る時のチカチカ（測って見つけたもの）：
  - 屋上の建物の外かべ（地面まで）が曲がり角の先まで続いていた。かべは床より後に描くので、角で赤い階段の上に、ベージュのぎざぎざの板が 2〜3 枚かぶって見えた（今の公開版でも同じ。写真で確認）。
  - 屋上のまん中の石の通路が、曲がり角（次の階段の床）の上まで続いていた。
  - 屋上のエレベーターの塔（赤白の帯）が、赤い箱の上に少しだけ大きい白い帯の箱を重ねた作りで、赤と白の面の前後が毎コマ入れかわっていた（階段のどこからでも見えるので、ずっとチカチカ）。
  - 曲がっている間、2〜3 本先の道（展望台・空）のチモシーまで描いていた。
  - 外階段の金網の柱（1.2m ごと）が、遠くで 1〜2 ドット間隔の縞になってちらついた。

## 直したこと

### 降りる時（ぐるっと見わたす）

4. [S1] 回り始めは 10m 飛んでから（飛び立ちの持ち上がりと重ならない）。
5. [S2] 回っている間は、カメラを水平近くまで上げて遠くの景色を見る（下の道ばかり見て「道が回る」ように見えない）。
6. [S2] 上げ下げは、ゆっくり入って、ゆっくりもどる（回り始めの 20%・終わりの 30% でなめらかに）。

### 塔の向きの矛盾

19. [L1] 「まっすぐ出る」も決められるようにした（straightOut）。
20. [L1] 赤い電波塔：足もとから入口の建物へは、まっすぐ（塔に向かって進む）。
21. [L1] 入口の建物 → 屋上は右へ（今までのテストの「右に曲がって屋上へ」と同じ）。
22. [L1] 屋上 → 外階段は左へ（階段は塔の方角＝正面に登る）。
23. [L1] 外階段 → 500 段からの通路は、まっすぐ。
24. [L1] 通路 → 展望台は左へ（展望台の向きが、景色を決めた向きから 25 度以内になる）。
25. [L1] 押上：足もとから入口へは、まっすぐ（塔に向かって進む）。
26. [L1] 押上：入口 → エレベーター、展望デッキ → エレベーターも、向きを決めた（毎回同じ）。
27. [L2] 道の本当の向き（face）は、場所ごとの数ではなく「一つ前の道の向き＋実際に曲がった向き」から求める。
28. [L2] 塔・山・都庁などの目印の方角は、この向きから計算する（右に曲がれば、塔は左へ動く）。
29. [L2] 下の町の地図（空の上・展望台）の向きも同じ向きから。
30. [L2] エレベーターの中だけは外が見えないので、場所で決めた向きにもどしてよい（押上の 350m・450m の景色はそのまま）。
31. [L2] 向きは、道を作った時（一つ前の道がまだある時）に一度だけ求めて覚える（あとで変わらない）。
32. [L3] 赤い電波塔の足もとの向きを、外階段と同じ向き（250 度）にした。塔は足もとで正面、階段でも正面。

### 登る時のチカチカ

38. [F3] まっすぐつながった次の道のチモシーは、いつも描く（階段 → 通路の境目で、急に出てこない）。
