# 収益化の方針（オーナーと相談して決定：2026-11-08）

目標は遊んだ人 100万人。人気を落とさないことを最優先にして、収益は次の形だけで少しずつ。

## やること
1. **自社サイト版（hay-dash.coana.co.jp）は広告なしのまま。** 課金要素も作らない。
2. **応援（投げ銭）**：itch.io の「$0 or donate」。遊ぶのは無料のまま、応援したい人だけ。受け取り設定（PayPal など・税の情報）はオーナーが行う。
3. **ゲームサイトの収益分配（CrazyGames）**：CrazyGames の中で遊ばれたときだけ、その SDK を読み込む（src/7b_portal.js）。
   - 広告は「見たい人だけ」：続ける画面の「広告を見て続ける」（ごほうび広告）。最後まで見たら続きから走れる。勝手に流れる広告は付けない。
   - feed.json の `"cgAds": true` で入る（最初のテスト公開＝Basic Launch の間は広告禁止なので false のまま）。
   - CrazyGames の中では、外へ出るリンク（共有・公式サイト・遊び方・ランキングページ・SNS）を出さない（先方のきまり）。
   - テスト：qa/portal.js（自社サイト版で SDK を読まないことも確かめる）。
4. **キャラクターで稼ぐ**：LINE スタンプ（レン・ジル・ポムの会社員スタンプ 16個）。画像の作り方は rig/ep/stk.js。

## やらないこと
- 遊んでいる途中に勝手に出る広告、バナー広告。
- 有料アイテム・ガチャ（相談なしに作らない）。
