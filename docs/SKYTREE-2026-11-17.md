# 押上の電波塔のルートを本物どおりに — 2026-11-17

調べた本物の順（展望台へ上がる人の道すじ）：
1. 4 階の入口：チケット売り場・列・案内
2. 4 台のエレベーター：かごの中は四季（春・夏・秋・冬）の絵。約 50 秒で 350m へ
3. 350m の展望デッキ：3 階建て。5m をこえる大きなガラスが 360 度。いちばん下の階にガラスの床
4. 2 台目のエレベーター（窓のあるかご）で 445m へ
5. 445m の展望回廊：ガラスの筒の中を、塔のまわりを回りながら、ゆるい坂で 450m まで上がる。いちばん高い所は 451.2m

## 直したこと
- S1. 新しい場所「押上の電波塔・4階の入口」（前は、川べりからいきなり 350m のデッキだった）
- S2. チケット売り場・案内・ポスター（赤い電波塔の入口と同じ作りを、白とグレーの明るい内装で）
- S3. 四季の絵のエレベーターの扉：扉の上に、春＝桜・夏＝花火・秋＝紅葉・冬＝雪の板
- S4. 扉の上の行き先「天望デッキ 350」と、上り下りのランプ（夜は光る）
- S5. 銀の扉と合わせ目
- S6. 展望回廊は、ゆるい坂で本当に 5m 上がる（前は平らなまま、数字だけ 445→451）
- S7. 展望回廊に着いた時のひとこと「2台目のエレベーターで445m。ガラスの筒のゆるい坂を、450mへ」（4 言語）
- S8. 4 階の入口に着いた時のひとこと（4 言語）
- S9. オオタカで降りる場面（隅田公園へ）も、赤い電波塔と同じ作り直しが入る（降りる先に公園・かげ・足をはなす）
- S10. 見張り：qa/towercourse.js を新しい順（川べり → 4 階の入口 → 350m → 445m → 空 → 着地）に

## まだ
- 展望回廊は、本物はらせん（塔のまわりを回る）。ここでは、まっすぐの坂のまま
- 350m のデッキの「ガラスの床」の場所だけを特別に作ってはいない（床の下に町が見える作りは前からある）
