# 2026-11-20 チカチカ・床が透ける・降りる時に道が動く（100 以上の改善の記録）

## オーナーの依頼
- 「障害物や壁がチカチカしたり、床が透けたり、高いところから下に降りるときに道路が動いてしまったりするようなバグが全体的にたくさん残っているので、この内容について改善のためのブラッシュアップを最低 100 以上、あらゆる角度から行なってください」

## 調べ方（数で見えるようにした）
- チカチカ（描く順の入れかわり）：重なる 2 つの物の描く順が、コマごとに行ったり来たりする組を数える（スクラッチの flick.js）。
- チカチカ（画面の点）：カメラを 3cm ずつ前に進めながら 10 コマ描き、色が A→B→A と大きく入れかわる点を数える（flickpx.js）。同じ場面で、直しを入れた版と外した版をくらべる。
- 床の穴：ふつうの絵と「空だけ」の絵をくらべ、地平線より下で空が見えている点を数える（holes.js）。
- 降りる時：赤い電波塔の展望台からオオタカと降りる所を 0.12 秒ごとに写して並べる（descend.js）。

## はじめに見つかったこと
- 調べた 40 か所で、描く順が行ったり来たりする組が 2,368 組。いちばん多いのは「重ねた箱の面どうし」（いすの座面と台、看板と柱、ビルの帯と柱）。
- 箱の面は「面のまん中までの深さ」の順に描いていたので、となりの面と深さがほぼ同じ時、カメラが少しゆれるだけで順番が入れかわっていた。
- 床の上にはった平らな絵（店先のくぼみ・明かりのにじみ・マット）どうしも、同じ平らな面なのに深さの順で描いていたので入れかわっていた。
- オオタカと降りる間、カメラが 1 回転していた（「東京をぐるっと見わたす」）。下に見える着地の道が画面の中を流れ、「道が動く」ように見えていた。
- 板と板・段と段のすき間（1 ドット）から、地平線の下に空（室内は天井）の色がのぞいていた。

## 調べ方（第 2・3 回で足したもの）
- 走りながらのチカチカ（abflick.js）：本当に 1/60 秒ずつ走らせ、同じコマを「直しあり」と「直しなし（LODOFF=1）」の 2 通りで描いて、A→B→A と 1 コマだけ色が入れかわる点を数える（同じ場面なので公平）。
  - 寝室 14,238 → 4,889（約 3 分の 1）、電車の中 24,265 → 21,021、銀座 29,182 → 26,453、駅のホーム・渋谷はほぼ同じ（細い柱・横断歩道のはしなど、形そのものの細さによる分）。
- 床の穴（holes.js）：空を「赤むらさき」と「緑」の 2 色で描きわけ、地平線より下で色がちがう点＝うしろが見えている点を数える。床と壁の合わせ目をふさいで、3 か所で 7,020 → 3,466。
- カメラの急な動き（camjerk.js）：1/60 秒ずつ進め、カメラの高さ・向きの急な変わり目を数える。
- 出たり消えたり（blink.js）：毎コマ描いた物を覚え、1 コマだけ描かれなかった・1 コマだけ描かれた物を数える（曲がり角で多い。多くは手前の壁にかくれて見えない）。
- ためしてやめたこと：箱の面の順番を決める範囲を 35m → 60m に広げても、チカチカは減らなかった（重くなるだけなので 35m のまま）。
- 第 3 回の終わり（同じ走り・同じコマで、直しなし → あり）：寝室 8,606 → 3,568、台所 4,159 → 3,536、銀座 18,604 → 16,313、通り 29,446 → 27,048、電車の中 20,283 → 17,723。
