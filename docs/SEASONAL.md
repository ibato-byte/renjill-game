# 季節の企画（自動）

## しくみ
- 企画は「キット」：src/1_data.js の `EV_KITS`（飾り `deco`、タイトルのお知らせ `gift`）＋ `CLOSET` の `ev: '<キット名>'` の帽子（無料プレゼント、期間中に1回自動でもらえる）。
- いつ動くかは次の順で決まる：
  1. アドレスの `#ev=<キット名>`（確認用）
  2. app/feed.json の `events`：`[{ "id": "xmas", "from": "2026-12-01", "to": "2026-12-25", "gift": { "ja": "…", "en": "…" } }]`（`eventsOnly: true` で下の暦を止める）
  3. 組み込みの暦 `EV_CAL`（お正月・バレンタイン・お花見・七夕・ハロウィン・クリスマス）
- 今あるキット：halloween（かぼちゃ）、xmas（ツリー）、newyear（門松）、valentine（ハートの箱）、hanami（桜の鉢）、tanabata（笹飾り）。

1. これから4週間の行事を調べる（日本の祝日・行事、季節のイベント、学校・会社の行事：決算期、新年度、ボーナス、年末進行、梅雨、花火…）。
2. 今の流行りを Web で調べる（話題の季節ネタ・天気・食べ物・会社員のあるある）。使うのは「なぜ人気か」だけ。ブランド名・他社キャラ・実在の人は使わない。
