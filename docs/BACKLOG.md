# 改善の候補（効果の大きい順。済んだら KAIZEN.md に移す）

1. 最初の30秒：初めての人がすぐ「おもしろい」と思えるか（チュートリアルの長さ、最初のごほうび、最初の失敗のやさしさ）。1回目で離れる人を減らす。
2. 毎日来たくなる：連続出社ボーナスの見せ方、今日のチャレンジ、週の目標、季節の企画の告知。
3. シェア：結果の画像（スコア・場所・ポム）を「送りたくなる」ものに。ストーリーズ用の画像の改善。友だちの記録への挑戦リンク（?beat=スコア）。
4. ご意見ボタン（Firestore の feedback に書くだけ。読むのは Hub。rules の追加が必要＝オーナーの承認）。
5. 新しいエリア（谷根千の路地、空港、朝の市場 など。実在の施設名・ロゴは出さない）。
6. ポムの出番を増やす（ポムで走れるモード、ポムのミニイベント）。アニメのポム回と同じしぐさ（ほおぶくろ）。
7. 音：エリアごとの BGM、効果音の気持ちよさ（自作の音だけ）。
8. 遅い端末での動き（qa/longrun.js の maxDt・メモリ）。
9. アクセシビリティ（色の見分け、揺れを減らす設定の範囲）。
