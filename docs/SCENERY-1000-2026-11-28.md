# 景色 1000（2026-11-28 から）

オーナーの依頼（11-28）：プレイ中の全ステージの質をより一層向上させたい。現実に近い作り込まれたクオリティにするために、全ステージをブラッシュする前に、そのステージに関わる現実の情報や画像などを色々とインプットして、景色をブラッシュアップする改善を、様々な角度から最低 1000 以上。全ステージ満遍なく、全てのステージが最高の景色で感動されるように、徹底的にリサーチを行いながら。

結果：**1060 件**（ステージごとの改善 971 件・全ステージで使う部品の作り込み 89 件）。全 130 ステージ（タイトルの寝室をのぞく、遊べる全部）に 1 件以上。

決まり（CLAUDE.md）：会社・ブランドの名前やマークは描かない（地下鉄の出入口も会社のマークなし・酒だるも銘柄なし・飛行機も会社の色なし）。人物の像は、実在の人ではない形だけ。画面の文字は増やさない（標識・札など、町にもともとある物の字だけ）。

## 調べたこと（主なもの）
- 銀座通り（中央通り）：街路樹は低い木の時代のあと、高い木の **カツラ** を植えた。歩道は御影石。照明灯は **ガス灯をイメージしたデザイン**（銀座・京橋・日本橋の中央通り 2.9km）。建物の高さと外観がそろっている。休日は歩行者天国。冬は **イチイの木がクリスマスツリー** になる（国土交通省 関東地方整備局・観光社会資本の資料）
- 丸の内仲通り：石だたみの道・両側に **ケヤキ・カツラ・シナノキ** の並木・アート作品。昼は車を止めて **テーブルを置くテラス**（平日 11〜15 時）・**キッチンカー**。冬（11 月〜）は **シャンパンゴールドの電球色だけ** のイルミネーション。秋はイチョウやケヤキが色づく（千代田区観光協会・丸の内の紹介）
- 日比谷公園：日本で最初の西洋風の公園（1903 年）。**大噴水**（24 通りの水の形・夜はライトアップ）・**第一花壇とペリカンの噴水**・**雲形池（鶴の噴水・紅葉）**・心字池・**つつじ山**・首かけイチョウ・公会堂（市政会館）。春はチューリップとネモフィラ（東京都建設局の資料・紹介記事）
- 隅田川の橋：構造も色もそれぞれちがう「橋の展覧会」。**蔵前橋は稲のもみがらをイメージした黄色**。12 の橋をライトアップ（東京都建設局）
- 西新宿：4 号街路（新宿駅から中央公園へ）・超高層ビルの足もとの広い歩道と公開空地（東京都都市整備局）
- そのほか、場所ごとの本物（明治神宮の奉献酒樽とクスノキの森・不忍池のハスと弁天堂と柳・清澄庭園の磯渡りと涼亭とカメ・浜離宮の刈り込んだ松と茶屋と汐留の高層ビル・小石川後楽園の円月橋と通天橋・増上寺の千躰子育地蔵・根津神社のつつじ・神田明神の随神門と甘酒・柴又の二天門と草だんご・御茶ノ水の楽器店・御徒町の宝石店・竹芝の島への船・羽田の飛行機・地下鉄の出入口の駅と線の色・都バスの停留所の名前・交差点の名前 など）は、一般に知られている事実をもとにした。迷った物（橋の色などで、資料で確かめられなかった物）は入れていない

## 気をつけたこと（新しいバグを出さない）
- 部屋のテーマには季節のテーマを作らない（季節のテーマの base が、部屋のかべの下の色 base と名前がぶつかり、ゲームが止まった。季節の物は、その日の季節で直接置く）
- 遠くの絵は、見える距離（120m）の中に置く（前の方・斜め前。真横の遠くは画面に入らない）
- 公園・お堀・池・水辺には電車を走らせない（オーナーの前の決まり・qa/trainplace）。本物では四谷・市ヶ谷の外堀ぞい、北十間川、天王洲に電車が走るが、決まりを守って高架の電車は新橋の駅前だけにした
- 足した絵が多く、スマホの絵のメモリが上限に近づいた（qa/memlong）→ 景色 1000 の絵は、スマホでは 5 割ほどの大きさの画用紙に描く（PC は 8.5 割）。信号の夜の絵は作らない
- 1 行に並べて決めた名前（const A = …, B = …）がほかのファイルとかぶり、ゲームが動かなくなった（BUS）→ **qa/rxnames.js を足した**（qa/dupcheck は行の最初の名前しか見ない）
- 池の前の木は、2 列目を全部・1 列目を 3 本に 2 本ぬいて、木の間から池が見えるように
- 自転車ナビマークは、日本は左側通行なので左右で矢の向きを逆に
- 季節の絵（ハス・あじさい・花だん・部屋のこたつなど）は、その日の季節（道を作る時の日）で決める
- 確かめ：python3 build.py → node qa/run-all.mjs quick（全部合格）・スマホ（390×844）と PC（1280×800）で、全ステージを昼・夕方・夜・季節ごとに撮って目で確かめた
